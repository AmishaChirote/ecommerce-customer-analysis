# E-Commerce Customer Analysis using Hadoop MapReduce

This project analyses large-scale e-commerce transaction data using Hadoop Streaming and Python MapReduce. The application performs customer-wise transaction analysis, spending analysis, customer classification, and performance comparison with and without a Combiner.

## Project Structure

- code/ - Mapper, Combiner, and Reducer scripts
- dataset/ - Transactions dataset used for analysis
- report/ - Activity report
- screenshots/ - Execution and output screenshots

## Dataset

The dataset contains 100,000 e-commerce transaction records with customer details, product information, transaction status, and payment methods.

## Features

- Customer-wise transaction analysis
- Customer spending analysis
- High-value transaction identification
- Customer classification
- Hadoop Streaming implementation
- Performance comparison with and without Combiner

## Technologies Used

- Python
- Hadoop Streaming
- HDFS
- MapReduce
